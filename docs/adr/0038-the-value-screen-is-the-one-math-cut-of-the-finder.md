# The value screen is the one math cut of the Finder

The Finder narrows trades with Jev judgments, and code keeps only the hard legal rules (memory `no-math-filters`). The fair-first Finder builds four shapes, and without a cut a press holds 95,000 to 242,000 trades, far past what Jev can read. Brian allowed one exception on 2026-11-19 (spec `deadline-week`, decision 14): the Value screen, a code cut on the sums of the trade chart values. Only the Value screen may drop a trade by math. Every other step of the Finder keeps the rule, and fairness itself stays a Jev judgment.

## Considered Options

- A Jev question on every trade with no cut. Jev reads 95,000 or more trades per press, and the requests pass the context limit.
- One relative band, the same for each shape. It keeps uneven trades where the side that gets more players also gets less value.
- A band with a direction, a floor per player, and no cap. Brian chose this one.

## Consequences

- The Value screen has three rules. The side that gets more players gets 100% to 125% of the sum of the other side. A 1-for-1 stays within 10% either way. Each player on a side of two or three players has at least 5 chart points.
- A player with no chart value never enters a Value offer. The Spares tree can still offer him.
- No cap ranks the trades after the band. A later cap needs a new decision under this ADR.
