# 04: How do we name a sheet and the menu sheet?

Map: `.scratch/ui-sdk-sheet/MAP.md`.

**Kind:** grill

**Blocked by:** none

**Status:** done

## Question

The glossary says a Sheet rises from the bottom and the Menu has two forms. `menu-sheet` drops from the top. ui-sdk names its part `Drawer`, a word on the Avoid list.

## Decision

Sheet means a panel that moves in from an edge over the dimmed page. Menu gets a third form, the menu sheet. "Drawer" stays on the Avoid list in prose and copy; `Drawer` in code is a Technical Name of ui-sdk. `GLOSSARY.md` holds the change. Brian decided it in the grill of 2026-11-14.
