# 18: Where do the easter eggs of the report hide, and how does a finder win the prize?

**Blocked by:** 14

## Question

Brian wants easter eggs throughout the report. One of them wins an Amazon gift card. The spec needs the number of eggs, where each hides, how hard each is to find, what each reveals, and how Brian names the winner.

The repo is public and the site is static, so the page and the repo must never hold the gift card code. A reader of the source can find a trigger without the hunt. One safe shape: the egg tells the finder to text Brian a screenshot. The first finder wins, and Brian sends the card by hand. A word that changes with each build can make the claim harder to fake.
