The method of this test, round 2 on 2026-11-17. The evidence agent wrote a Playwright script, because no step verb of the evidence runner covers it.

1. A detached worktree of 7b1d09c7, the head of the Spec branch, holds the build.
2. In it: pnpm install, then CLIENT=<client> NEXT_PUBLIC_API_URL=http://localhost:8080 pnpm build for cpc and norcal. Each export is copied to a scratch folder.
3. make -C apps/api api-evidence runs from the same detached worktree on port 8080, with real Sleeper data and real Claude calls.
4. The script serves the export on http://127.0.0.1:4173 with apps/site/e2e/serve.ts, so a missing path gets 404.html with status 404.
5. Each page is a fresh browser context at the width, 900 px tall, with motion on unless the test says reduced motion. apps/site/e2e/floor.ts openPage sets cpc.theme before the first paint. The harness gives the load 30 s and one retry.
6. The passphrase localtest sits in localStorage key cpc.passphrase, so no dialog covers the page.
7. A held request: a Playwright route on the analyze POST waits. A test that needs the answer then calls route.continue(), so the real request goes on to the local API. No answer is made up.
8. Off-machine calls are not blocked, so the headshots load from sleepercdn.com through the real teams route of the local API.

The scripts are in evidence/harness/. Run from apps/site: EV_TESTS=<folder of the scripts> pnpm exec playwright test --config pw-evidence.config.ts <spec>.

The test of this folder: grade.spec.ts, tests "R0 the first real grade of trade T and of the norcal trade" and "AT-10, 11, 12, 17, 26, 30, 31 on a cached grade of trade T". Its log is output.txt.

What the script does for this test:
R0 makes the first real grade of trade T on this run at 1280 px dark, so each later grade of the same trade is a cached repeat; answer-T.json is the real answer of that grade. Then one session per width and theme: the script opens trade T, waits for the idle mesh to stop, starts the reveal watch and the row light watch, and taps Grade the Trade. The real analyze POST goes to the local API with no hold. The reveal watch reads data-mesh-flash and data-mesh-pulls of the read canvas on each frame (side 0 Bo Girds, side 1 Teehee). The row light watch (copied from apps/site/e2e/analyzer-stage.spec.ts) sums the light of the read canvas inside the box of each stage row, at the brightest frame with flash over 0.5, at the brightest frame with a pull over 0.45, and at rest 2.5 s after the read hero shows. The light of a pixel is its color times its alpha. The script waits 80 ms after the response, then shoots the read hero (flash), and shoots it again at about 650 ms (dip). The log gives the time each shot ended. The test ran twice; output.txt keeps the R0 lines and the lines of the second run, and every other file of this folder is from the second run. mesh-1280-dark.json holds each sample at 1280 dark. At 1280 px dark the context records a video of the reveal (video-reveal-1280-dark.webm).
