# 01: The answer key

Map: `.scratch/manager-brain/MAP.md`. Ticket: `decisions/01-grill-answer-key.md`.

Brian grades each trade for the **asker**, the team named first, as of the week of the trade, with no hindsight.

- **Lean** is one of: Send it, Lean yes, Gut call, Lean no, Pass.
- **Why** is one or two lines, in the voice the judge should use.
- **Accept** is only for set 2 and set 3: would the other manager accept? Yes, no, or maybe. A real trade of set 1 has Accept yes, because he did.
- **Hindsight** is optional, for set 1 only: a note such as "good call that went bad". It is not the label.
